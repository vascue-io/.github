# Vascue organization profile

This repository contains Vascue's public GitHub organization profile and stable machine-readable company metadata.

Vascue is an AI-native healthcare operations automation company. Its AI Front Desk and Visibility & Analytics are live; Vascue Claims is available through a design-partner programme. Agent-based clinic booking remains a research project, not a public production API.

## Contents

- [profile/README.md](profile/README.md): rendered on the [Vascue GitHub organization](https://github.com/vascue-io)
- [llms.txt](llms.txt): concise AI-readable status and links
- [company.jsonld](company.jsonld): Schema.org Organization data, matching the node on www.vascue.io
- [SECURITY.md](SECURITY.md): vulnerability reporting and sensitive-data rules

## Canonical sources

The website is the source of truth for product availability:

- [AI-readable company summary](https://www.vascue.io/llms.txt)
- [Claims overview](https://www.vascue.io/claims-automation.md)
- [Claims FAQ](https://www.vascue.io/claims/faq)
- [Security and privacy](https://www.vascue.io/security)

Keep product status aligned with the website when updating this repository. Production evidence from the live patient-communication deployment must not be presented as claims-product or agent-booking results.

Do not submit patient information, policy numbers, clinical documents, credentials, tokens, or clinic-system keys through GitHub.
